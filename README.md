# ピアノコード帖

C4〜C5 の1オクターブで押さえるピアノコード一覧アプリ（144コード）。

- 🎹 演奏：タップで鳴らす／Launchkey（MIDIキーボード）で弾いた音とコード名の表示／弾いた履歴／コード設計スタジオ
- コード一覧（解説）：C メジャー・A マイナーでの使い方と進行例
- 📓 ノート解説：手書きの音楽理論ノートの書き起こし
- `piano-chord-book.pdf`：印刷用PDF

## 使い方
GitHub Pages で公開すると、パソコンの Chrome / Edge で Launchkey（Web MIDI）が使えます。
スマホでは「ホーム画面に追加」でアプリのように開けます（アイコン・名前は「コード帖」）。
