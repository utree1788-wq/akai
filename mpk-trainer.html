スケールガイド

青い鍵盤がスケールの音、赤がルート音です。スケール外の音を弾くと下に表示されます。MPK mini plus 本体の SCALES 機能（スケール外の音を出さない機能）を使う前の、指の形の練習に。

耳コピ

パッドのリズム練習

メトロノームに合わせてパッド（どれでも可）を叩くと、ズレをミリ秒で表示します。中央より左が早い（走り）、右が遅い（もたり）。±20ms以内を目指しましょう。

アルペジエーター（ARP）

和音を押さえるだけで、その音を順番に自動で弾いてくれる機能。シンセのフレーズ作りに一番効きます。

  1. ARP を押してオン（点灯）。
  2. コード（例：C・E・G）を押さえる → 分散和音が流れる。
  3. TAP TEMPO を数回叩いて速さを決める。

設定（鍵盤の上の印字）

鍵盤の上に印字された項目は、アルペジオ設定中に鍵盤を押して選べます（SHIFT＋ARP で設定画面）。ノブの下の枠付き文字（DIVISION / SWING / MODE / OCT / LATCH / SYNC / GATE / BPM）も同じ設定をノブで変えるためのものです。

項目意味

UP / DOWN / INCL / EXCL / ORDER / RAND弾く順番。上がる・下がる・往復（端の音を重ねる/重ねない）・押した順・ランダム。
LATCH手を離してもアルペジオが鳴り続ける。ラッチ中に別のコードを押すと切り替わる。

パッドの使い方：NOTE REPEAT・FULL LEVEL・BANK
  • NOTE REPEAT：オンにしてパッドを押し続けると、テンポに合わせて自動で連打。ハイハットの16分刻みやトラップのロールに。押す強さで音量も変わります。
  • FULL LEVEL：叩く強さに関係なく最大ベロシティ（127）で鳴る。打ち込みの音量をそろえたいときに。
  • BANK A/B：パッド8個を2バンク＝16音として使える。A にキック・スネア・ハット、B にパーカッションなど。

パッドは通常 MIDIチャンネル10 で送られます（ドラム用の慣例）。このアプリもチャンネル10のノートをパッドとして扱います。

SCALES と CHORDS（音楽理論の補助輪）
  • SCALES：選んだスケール（例：Cマイナー）以外の音が出ないようにする。適当に弾いても外れないので、メロディ作りの入り口に最適。
  • CHORDS：鍵盤1つでコード（和音）全体が鳴る。コードを知らなくても伴奏が作れる。

おすすめは「本体の機能で鳴らしてみる → このアプリのコード練習やスケールガイドで自分の指でも弾けるようにする」の往復。モニター画面では本体から出たノートをそのままコード判定するので、CHORDS が何を鳴らしているかも分かります。

内蔵シーケンサー（STEP EDIT / LIVE SEQ）
  • LIVE SEQ（SHIFT＋OCT＋）：REC → PLAY で演奏をそのまま録音。ループしながら重ね録りができます。
  • STEP EDIT（SHIFT＋OCT−）：1ステップずつ音を入力。◀◀ PREV STEP / ▶▶ NEXT STEP でステップを移動。
  • 消すときは SHIFT＋TAP TEMPO（CLEAR DRUM）、SHIFT＋FULL LEVEL（CLEAR KEY）。
  • パソコンなしでもフレーズのスケッチができ、MIDI OUT や CV/Gate 出力からハードウェアのシンセも鳴らせます。
DAW・アプリと組み合わせるコツ
  • ノブの送るCC番号はプログラム（PROG SELECT）ごとに違うことがあります。「設定」タブのノブ学習で、このアプリにも実際の番号を覚えさせられます。
  • DAWでは「MIDIラーン」機能でノブをフィルター・リバーブ量・音量に割り当てるのが定番。
  • PITCH ホイールの幅は音源側で決まります（このアプリは K7 で変更）。
  • レイテンシー（遅れ）を感じたら、DAWのオーディオバッファを小さく（128〜256）するのが効果的。
